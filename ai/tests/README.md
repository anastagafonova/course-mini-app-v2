# AI Tests

В эту папку будут добавляться тестовые вопросы и сценарии для проверки качества ИИ-ассистента.

Примеры:
- пользователь хочет дом 250 м² без понимания сценария жизни
- пользователь выбирает между одноэтажным и двухэтажным домом
- пользователь хочет сократить бюджет без потери качества
- пользователь спрашивает вне зоны компетенции ассистента
